## What is measured and what is not

Kind, range and file counts are **measured over every file of that
type on the disc**. No English gloss is attached to any key here:
"`TurnRate` is how fast the character turns" is a guess, while
"`TurnRate` is a float present in all 181 characters, measured
0.5 .. 12.0" is a fact, and it is the fact that lets someone edit
the file with their eyes open. Inference belongs in
`UNKNOWNS.md`, labelled as inference.

**`ref` is the exception, and it is still mechanical.** A string
key is marked `ref` when at least half its values match the base
name of a real file on the disc; the arrow shows which extensions
those files have. That turns `4213` opaque text keys into "this one
names an asset of type X" without anyone guessing.
