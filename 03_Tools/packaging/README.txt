RDR MODDING STUDIO
A modding tool and 3D level editor for Red Dead Revolver (PS2, USA, SLUS-20500)

START
  1. Unzip the whole folder. Keep "_internal" next to the .exe.
  2. Double-click "RDR Modding Studio.exe". If Windows says "Windows protected
     your PC", click "More info" > "Run anyway" (the app is not code-signed).
  3. Answer the setup screens once: point it at your own disc image, and it
     makes a working copy that every edit goes to.

The full user guide, modding guide and custom-models guide are inside the
app: the "Guides" button in the bottom bar.

If nothing opens (or the window is blank), install the free Microsoft Edge
WebView2 runtime: https://developer.microsoft.com/microsoft-edge/webview2/
"RDR Modding Studio.exe" --reset forgets your setup; --debug shows a console.

IMPORTANT
  * No game data is included. You need a disc image made from a copy of the
    game you own. None is provided or linked.
  * Your original disc image is opened read-only and never written. All edits
    go to a copy; "Reset to stock" rebuilds that copy from the original.
  * No network connections, no telemetry, no account.
