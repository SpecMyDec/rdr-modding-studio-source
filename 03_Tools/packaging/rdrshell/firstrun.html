This tool ships with no game data whatsoever. It contains no code, art, audio, text or level data from Red Dead Revolver. Everything it shows you is read live out of a disc image that you supply.

You need your own copy of the game. Red Dead Revolver (PlayStation 2, USA, SLUS-20500) is owned by Take-Two Interactive. You must dump the disc image yourself from a disc you own. This tool will not help you obtain one and no download link will ever be provided.

Your original is never modified. The file you point at is opened read-only and copied once. All editing happens on that copy. If the copy breaks, you make a new one in one click.

It can still break your copy. Every write is previewed before it happens and recorded so it can be undone, but this is a tool for poking at a twenty-year-old game's internals. Save often, keep checkpoints, and do not point it at the only disc image you have.
